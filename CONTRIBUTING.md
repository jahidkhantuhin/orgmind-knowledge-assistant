# Contributing

Thanks for helping improve OrgMind. Keep changes focused, use TypeScript strict mode, and add or update tests for behavior changes. Run `pnpm lint`, `pnpm typecheck`, and `pnpm test` before opening a pull request. Husky runs these three checks sequentially before a normal Git push and blocks it at the first failure. Start Docker services before pushing when you want MongoDB-dependent integration tests to run rather than skip. GitHub Actions remains the shared CI check.
